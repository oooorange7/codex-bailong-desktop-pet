# 个人修改版 0.8.5

本分支基于上游 v0.7.9，提交 `d81c135cc55527390a4e545dfdce90abe27fb1f7`；0.8.5 另从上游 0.9.3 移植状态图标动画。版本号属于这份个人修改，具体合入范围如下。分支名继续使用 `personal-v0.8.4`，仓库 `main` 保留 Fork 时的上游版本。

## 修改内容

- 0.8.5 移植上游 0.9.3 状态图标：三颗有序水球整体旋转、交错换位、短暂黏连后分开，并逐轮更换黏连组合。正常卡片使用紫灰与薄荷色，深色胶囊使用适配深底的亮色。图形和颜色在同一控件内平滑变形；完成、等待、中断、未连接与待命有各自符号，完成提醒保留到用户确认，隐藏和静止时停止动画刷新。
- 默认关闭拖动惯性，将滑动与反弹开关放入“动作与陪伴”常用设置。
- 使用 Windows 界面字体与完整像素对齐，调整中英文及小号额度文字的字重和排版。
- 今日 Token 使用完整数字和千位逗号，例如 `87,990,123`。
- Token 日统计柱支持选择日期，标题使用 `M` 等紧凑单位；重复点击选中日期或点击统计范围恢复总量。普通数据刷新保留选择。
- 点击卡片外部回到胶囊，保留设置、聊天的未保存草稿。手动收起持续到用户主动展开，状态更新和任务完成不再把卡片顶开；原有闲置自动收起与新任务唤醒规则继续用于自动收起的卡片。
- 使用本机实时的明确空闲和回合终止信号清除残留执行状态；缺失、未知或旧回合信号不能误停正在进行的新任务。
- 系统弹窗通知默认关闭，可在“动作与陪伴”开启。胶囊内的状态和完成提醒仍更新。

## 数据行为与上传范围

以下说明针对本分支所检查的实现，不替代 Codex、模型服务或公告服务自己的隐私条款。

程序读取本机 Codex 日志、会话标题、部分公开消息和 Token 用量，用于本地状态与统计；账户额度通过本机 Codex 登录读取。独立聊天功能会将该功能自己的系统提示、限定长度的聊天历史以及相应 API 密钥发送给用户配置的模型服务。

重置公告来自 `codex-resets.com`，更新与资源下载连接 GitHub。API 密钥在 Windows 上通过 DPAPI 保存；加密凭据、聊天文件、统计数据库和部署备份仍属于不应上传的本机数据。

本分支不包含本机账号、聊天记录、统计数据库、诊断日志、验收截图、安装器或角色动画。Git 忽略规则已补充对应本机文件与专用脚本的排除项。上游已有文档媒体、字体及组件许可保留。

## 运行与更新

Python 3.12 与依赖、素材准备、源码运行和构建入口见 [开发说明](DEVELOPMENT.md)。Git 中没有角色动画，需要按说明准备兼容素材。运行源码前请隔离 `LOCALAPPDATA` 与 `CODEX_HOME`，避免测试程序写入日常使用的数据目录。
